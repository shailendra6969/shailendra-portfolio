# Shailendra Khandekar — Portfolio

Production-ready static portfolio showcasing data science, machine learning, computer vision, and agentic AI work.

## Adding a Project

Projects can be automatically added to this portfolio directly from GitHub without modifying the portfolio source code.

1. Create and push a public GitHub repository.
2. Add a clear, non-empty repository description.
3. Add the `portfolio` topic to the repository.
4. Optionally add the `featured` topic to highlight the project in the Featured section.
5. Add a useful `README.md` describing the project's purpose, methodology, results, and architecture where appropriate.
6. Refresh the portfolio website.

The portfolio automatically discovers, filters, caches, and displays qualifying GitHub repositories through the GitHub API.
