# Shailendra Khandekar — Portfolio

Production-ready, static data science and agentic AI portfolio website.

## Adding a project

To automatically publish and scale projects on this portfolio directly from GitHub without modifying website code:

1. Create and push your GitHub repository under your account.
2. Add a clear, non-empty GitHub repository description.
3. Add the `portfolio` topic to the repository topics.
4. Optionally add the `featured` topic to highlight one of your strongest projects in the Featured area.
5. Add a useful `README.md` containing the project's purpose, methodologies, results, and architecture/screenshots when appropriate.
6. Refresh the portfolio website.

No portfolio source-code change is required for a new automatically listed project. The portfolio continuously discovers, caches, filters, and displays your projects dynamically from the GitHub API.
